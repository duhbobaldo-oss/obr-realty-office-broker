# Offline map tiles (optional)

The application uses online map tiles first (OpenFreeMap / OpenStreetMap). An offline
fallback file `umaps-vector-B.pmtiles` (about 148 MB) can be placed in this folder; it is
not included in the repository because of its size and the licence of the underlying map
data (OpenStreetMap data is available under the ODbL). Without it, maps work whenever the
device is online.
